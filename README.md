# Angkat vision test

Browser-only pose tests (MediaPipe): lifting posture checks, a jumping-jack counter, and SEGAK test modes (Naik Turun Bangku, Tekan Tubi, Ringkuk Tubi Separa, Jangkauan Melunjur) graded with the norm tables from Panduan SEGAK (KPM, 2016). Camera frames stay in the browser.

Live: https://fikhri02.github.io/angkat-vision-test/
