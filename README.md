# Angkat vision test

Browser-only pose tests (MediaPipe): lifting posture checks, a jumping-jack counter, Coach Sado (a push-up coach who cheats the count), and SEGAK test modes (Naik Turun Bangku, Tekan Tubi, Ringkuk Tubi Separa, Jangkauan Melunjur) graded with the norm tables from Panduan SEGAK (KPM, 2016). Camera frames stay in the browser.

Abang Sado art from Warung Mek.
